# ELI5 ("explain like I'm five")

Can you take a step back and explain this with more background? Don't worry about telling me things I might already understand. I'd rather
have this framing include information I already understand, versus the risk of explanations that assume I know things I don't know.


## Naming note
The skill name "explain like I'm five" comes from a common internet expression used on forums like Reddit: "ELI5" is a response given when an answer or explanation involves too much jargon, assumed knowledge, etc. Sometimes it's meant literally, but in this case the name is adopted as shorthand. Your response doesn't need to literally be framed in terms a five-year-old can understand.
